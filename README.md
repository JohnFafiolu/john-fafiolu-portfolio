## Run locally

Open `index.html` in a browser. The site uses Google Fonts; the rest of the layout and illustrations are built with HTML and CSS.

## Publish with GitHub Pages

1. Create a GitHub repository named `john-fafiolu-portfolio` (or another name you prefer).
2. Upload the contents of this folder to the repository root. Do not upload the outer ZIP folder itself.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Your URL will appear in the Pages settings.

## Before publishing

- Review all project descriptions and links.
- The quality-control project uses simulated data; the page intentionally describes it as illustrative.
- The climate project is described as examining relationships, not proving causal impact.
- Add individual case-study pages later if you want more detail than the GitHub repository provides.
